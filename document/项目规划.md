# 项目规划 - 桌面悬浮 TodoList 工具

## 项目概述

### 项目名称
syj_require_list - 桌面悬浮待办事项管理工具

### 项目目标
创建一个轻量级的桌面悬浮 TodoList 工具，支持：
- 窗口悬浮显示和边缘吸附
- 手动输入待办事项
- 图片上传和 OCR 文字识别
- 数据持久化存储
- 打包成独立 exe 文件

### 核心特性
1. **悬浮窗口**：始终置顶，无边框，可拖拽
2. **边缘吸附**：拖到屏幕边缘自动吸附（类似 QQ）
3. **侧边隐藏**：吸附后自动隐藏，鼠标悬停展开
4. **待办管理**：添加、完成、删除待办事项
5. **图片支持**：上传图片，OCR 识别文字
6. **数据持久化**：SQLite 本地存储

## 数据模型

### Todo 数据结构
```typescript
interface Todo {
  id: number;                    // 主键
  content: string;               // 待办内容
  source?: string;               // 来源（手动输入/截图）
  imagePath?: string;            // 图片路径
  ocrText?: string;              // OCR 识别的文字
  createdAt: string;             // 创建时间
  expectedFinishAt?: string;     // 预期完成时间
  finishedAt?: string;           // 实际完成时间
  isCompleted: boolean;          // 是否完成
  order: number;                 // 排序（完成的排最后）
}
```

### 数据库表结构
```sql
CREATE TABLE todos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  source TEXT,
  image_path TEXT,
  ocr_text TEXT,
  created_at TEXT NOT NULL,
  expected_finish_at TEXT,
  finished_at TEXT,
  is_completed INTEGER DEFAULT 0,
  order_index INTEGER
);
```

## 窗口吸附功能实现总结（2025-12-21）

### 功能概述
实现了完整的窗口边缘吸附、拖动预览、自动隐藏功能，分三个阶段完成：

**第一阶段：窗口吸附 MVP**
- 自定义拖动实现（mousedown/mousemove/mouseup）
- 边缘检测（10px 触发距离）
- 支持左、右、上边缘吸附
- 从吸附状态拖动时恢复原始尺寸（保持当前位置）

**第二阶段：拖动预览**
- 独立预览窗口（半透明灰色框）
- 实时预览吸附后的位置和尺寸
- 100ms 节流（10fps 更新）

**第三阶段：自动隐藏**
- 吸附后立即自动隐藏（无延迟）
- 只保留 10px 可见区域
- 鼠标悬停时展开窗口
- 鼠标离开时立即隐藏
- 150ms 平滑动画（15fps，easeInOutCubic 缓动）

### 关键技术决策

1. **拖动实现方式**：自定义拖动 vs `startDragging()` API
   - 选择：自定义拖动
   - 原因：`startDragging()` 立即返回，无法准确检测鼠标松开时机

2. **预览框实现方式**：独立窗口 vs DOM 元素
   - 选择：独立 Tauri 窗口
   - 原因：主窗口拖动时 JavaScript 可能被阻塞，独立窗口不受影响

3. **位置检测方式**：前端监听 vs Rust 轮询
   - 选择：前端监听（自定义拖动后）
   - 原因：自定义拖动后，前端可以直接控制，无需 Rust 轮询

4. **鼠标检测方式**：Rust 追踪 vs 前端事件
   - 选择：前端 mouseenter/mouseleave 事件
   - 原因：10px 可见区域足够大，直接监听窗口事件即可

### 性能优化

1. **拖动性能**：RAF 节流（60fps）
2. **预览更新**：100ms 节流（10fps）
3. **动画性能**：150ms 时长，15fps 帧率（减少 IPC 调用 85%）
4. **防止重复调用**：isHiding/isShowing 标志
5. **防止窗口超出屏幕**：先设置位置，再设置尺寸

### 参数调整历程

| 参数 | 原计划 | 实际实现 | 变更原因 |
|------|--------|----------|----------|
| 吸附触发距离 | 10px | 10px | 未变更 |
| 可见区域宽度 | 2px | **10px** | 用户反馈太窄 |
| 自动隐藏延迟 | 1秒 | **立即** | 用户要求更快 |
| 鼠标离开延迟 | 1秒 | **立即** | 用户要求更快 |
| 隐藏动画时长 | 300ms | **150ms** | 性能优化 |
| 动画帧率 | 60fps | **15fps** | 性能优化 |
| 拖动帧率 | - | 60fps | 自定义拖动 |
| 预览更新频率 | 50ms (20fps) | 100ms (10fps) | 性能优化 |

### 已解决的关键问题

1. **吸附时机不准确**：使用自定义拖动替代 `startDragging()` API
2. **拖动卡顿**：RAF 节流优化
3. **预览窗口架构**：单入口点，根据 label 渲染不同组件
4. **Race Condition**：复制 pendingPosition 避免异步操作期间被修改
5. **动画卡顿**：降低帧率到 15fps，减少 IPC 调用
6. **窗口闪烁**：添加 isHiding/isShowing 标志防止重复调用
7. **窗口超出屏幕**：先设置位置再设置尺寸
8. **可见区域太窄**：从 2px 增加到 10px
