# 项目规划 - 桌面悬浮 TodoList 工具

## 项目概述

### 项目名称
syj_require_list - 桌面悬浮待办事项管理工具

### 项目目标
创建一个轻量级的桌面悬浮 TodoList 工具，支持：
- 窗口悬浮显示和边缘吸附
- 手动输入待办事项
- 图片上传和 OCR 文字识别
- 数据持久化存储
- 打包成独立 exe 文件

### 核心特性
1. **悬浮窗口**：始终置顶，无边框，可拖拽
2. **边缘吸附**：拖到屏幕边缘自动吸附（类似 QQ）
3. **侧边隐藏**：吸附后自动隐藏，鼠标悬停展开
4. **待办管理**：添加、完成、删除待办事项
5. **图片支持**：上传图片，OCR 识别文字
6. **数据持久化**：SQLite 本地存储

## 技术栈

### 前端技术
- **框架**：Vue 3 + TypeScript
- **构建工具**：Vite
- **状态管理**：Pinia
- **日期处理**：dayjs
- **HTTP 请求**：Axios

### 桌面框架
- **Tauri 2.x**：Rust 后端 + WebView2 前端
- **优势**：
  - 体积小（10-15MB）
  - 内存占用低（30-50MB）
  - 性能好
  - 安全性高

### 数据存储
- **SQLite**：通过 sqlx crate 直接操作
- **存储位置**：`C:\Users\用户名\AppData\Local\syj_require_list\todos.db`
- **存储内容**：
  - 待办事项内容
  - 图片路径
  - OCR 识别结果
  - 创建时间、完成时间

### OCR 服务
- **百度 OCR API**
- **免费额度**：每天 500 次
- **识别率**：95%+

## 数据模型

### Todo 数据结构
```typescript
interface Todo {
  id: number;                    // 主键
  content: string;               // 待办内容
  source?: string;               // 来源（手动输入/截图）
  imagePath?: string;            // 图片路径
  ocrText?: string;              // OCR 识别的文字
  createdAt: string;             // 创建时间
  expectedFinishAt?: string;     // 预期完成时间
  finishedAt?: string;           // 实际完成时间
  isCompleted: boolean;          // 是否完成
  order: number;                 // 排序（完成的排最后）
}
```

### 数据库表结构
```sql
CREATE TABLE todos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  source TEXT,
  image_path TEXT,
  ocr_text TEXT,
  created_at TEXT NOT NULL,
  expected_finish_at TEXT,
  finished_at TEXT,
  is_completed INTEGER DEFAULT 0,
  order_index INTEGER
);
```

## 注意事项

### 开发注意
1. 修改 `tauri.conf.json` 后需要重启开发服务器
2. 修改 Rust 代码需要重新编译（增量编译约 1-2 分钟）
3. 修改 Vue 代码会自动热重载
4. 添加新权限时需要在 `capabilities` 中声明

### 性能优化
1. 限制并行编译任务数（如果内存不足）
2. 使用虚拟内存（如果物理内存不足）
3. 关闭不必要的程序（编译时）

### 用户体验
1. 窗口大小：320x600（适合待办列表）
2. 始终置顶：可通过图钉按钮切换
3. 无边框：通过标题栏拖拽移动
4. 边缘吸附：自动吸附到屏幕边缘
5. 侧边隐藏：类似 QQ 的体验
