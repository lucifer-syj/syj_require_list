```json
    "core:window:allow-start-dragging",
    "core:window:allow-set-position",
    "core:window:allow-set-always-on-top"
  ]
}]
```

## 遇到的关键问题和解决方案

### 问题 1：内存不足导致编译失败
- **现象**：`rustc-LLVM ERROR: out of memory`
- **根本原因**：用户电脑资源紧张，Rust 编译大型项目需要 4-8GB 内存
- **解决方案**：增加虚拟内存 + 限制并行编译
- **经验教训**：Tauri 开发时资源需求高，虽然运行时占用低

### 问题 2：Tauri 2.x API 兼容性
- **现象**：多个功能不工作（白屏、拖拽、关闭）
- **根本原因**：Tauri 2.x 相比 1.x 有重大 API 变化
- **关键变化**：
  - 窗口获取：`getCurrentWindow()` 而非直接导入 `appWindow`
  - 拖拽方式：`startDragging()` API 而非 HTML 属性
  - 权限系统：需要在配置文件中显式声明权限
- **经验教训**：使用新版本框架时要仔细查阅官方文档

### 问题 3：PowerShell 脚本编码问题
- **现象**：中文字符乱码导致脚本执行失败
- **根本原因**：UTF-8 编码的脚本被 PowerShell 5.1 用 GBK 读取
- **解决方案**：使用纯英文编写脚本，避免编码问题
- **经验教训**：跨平台脚本尽量使用英文，或明确指定编码

#### 9.4 关键技术问题解决

**问题 1：字段名映射错误**
- **现象**：图片路径保存了但前端获取为 `undefined`
- **原因**：Rust 使用 `image_path`（下划线），前端使用 `imagePath`（驼峰）
- **解决**：给 Rust 结构体添加 `#[serde(rename_all = "camelCase")]`

**问题 2：convertFileSrc 无法访问**
- **现象**：图片转换后的 URL 返回 `ERR_CONNECTION_REFUSED`
- **原因**：`asset.localhost` 协议在开发环境中不可用
- **解决**：
  1. 后端实现 `read_image` 命令读取文件
  2. 前端调用获取字节数组
  3. 转换为 Blob URL 显示
  ```typescript
  const fileData = await invoke<number[]>('read_image', { filePath });
  const uint8Array = new Uint8Array(fileData);
  const blob = new Blob([uint8Array], { type: 'image/jpeg' });
  const blobUrl = URL.createObjectURL(blob);
  ```

**问题 3：删除对话框权限错误**
- **现象**：`dialog.confirm not allowed`
- **原因**：使用了浏览器原生 `window.confirm()`，但缺少权限
- **解决**：
  1. 在 `tauri.conf.json` 添加 `dialog:allow-confirm` 权限
  2. 改用 Tauri 的 `confirm()` API
  ```typescript
  import { confirm } from '@tauri-apps/plugin-dialog';
  const confirmed = await confirm('确定要删除这条待办吗？', {
    title: '确认删除',
    kind: 'warning'
  });
  ```

**问题 4：删除待办后图片残留**
- **现象**：删除待办后，图片文件仍保留在磁盘
- **解决**：修改 `delete_todo` 命令
  1. 先查询待办的 `image_path`
  2. 删除数据库记录
  3. 删除关联的图片文件
  ```rust
  if let Some((Some(image_path),)) = result {
      let _ = fs::remove_file(&image_path);
      println!("已删除图片文件: {}", image_path);
  }
  ```
